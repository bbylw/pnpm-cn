title: "pnpm cache"
headingIds: []
---

管理 registry 元数据缓存：即 pnpm 从各 registry 下载并保存在 [`cacheDir`](/docs/settings/other#cachedir) 目录中的包元数据。

命令：

- [cache list](/docs/cli/cache-list)
- [cache list-registries](/docs/cli/cache-list-registries)
- [cache delete](/docs/cli/cache-delete)
- [cache view](/docs/cli/cache-view)
- [cache path](/docs/cli/cache-path)
- [cache prune](/docs/cli/cache-prune)
