使用 pnpm 在生产环境中部署依赖有两种方式。一种是提交锁文件，然后在生产环境中运行 `pnpm install`。它会依据锁文件构建依赖树，也就是说依赖版本与锁文件提交时保持一致。这是确保依赖树在各环境间保持一致的最有效方式，也是我们推荐的方式。

另一种方式是提交锁文件并把包存储复制到生产环境（可通过[存储位置选项](/docs/settings/store#storedir)更改位置）。之后运行 `pnpm install --offline`，pnpm 会使用全局存储中的包，不会向 registry 发出任何请求。**仅**当环境因故无法访问外部 registry 时，才推荐这种方式。
