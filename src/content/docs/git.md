## 锁文件

你应当始终提交锁文件（`pnpm-lock.yaml`）。这有诸多原因，其中主要原因是：

- 它通过跳过包解析，为 CI 和生产环境实现了更快的安装
- 它强制开发、测试和生产环境之间的安装与解析保持一致，意味着测试和生产中使用的包将与你开发项目时完全相同

### 合并冲突

pnpm 可以自动解决 `pnpm-lock.yaml` 中的合并冲突。如果你有冲突，只需运行 `pnpm install` 并提交更改。

不过请注意。我们建议你在暂存提交之前审查更改，因为我们无法保证 pnpm 会选正确的 head——它会使用最新更新的那个锁文件来构建，这在大多数情况下是最理想的。
